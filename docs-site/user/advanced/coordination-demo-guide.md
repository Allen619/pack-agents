# 协调编排演示（新手友好版）

这是一份“傻瓜式”操作指南，帮助你快速体验“协调内核”的效果。整个过程不影响现有功能，随时可一键关闭。

## 入口

- 页面：在左侧菜单点击“协调内核 Demo”，或直接访问 `/demo/coordination`

## 准备工作

1. 在“Agent 工厂”里先创建至少 1 个代理（Agent）。
2. 其余开关可在演示页面直接设置，无需改配置文件。

## 三步上手

1. 打开“协调内核 Demo”。
2. 在顶部“特性开关”里：
   - 建议先开启“影子模式”（只观察、不干预）。
   - 如需真实体验新调度，再勾选“启用新调度”并选择“Agent 白名单”。
   - “任务类型白名单”已为演示配置好（规划/执行/总结），不用改。
3. 选择三个代理：“规划代理 / 执行代理 / 总结代理”，输入任务描述，点击“运行编排”。

页面会自动展示：
- 总体指标：已指派、已完成、失败、重试、运行中、排队中。
- 每个代理当前关联的任务列表与状态（中文展示：已完成/运行中/排队中/等待中/已取消/失败）。

说明：演示会模拟“规划 → 执行 → 总结”三步流程的完成过程。实际环境中，应由你的执行器完成任务并把结果回写（演示仅做效果展示）。

## 关闭与安全

- 关闭“启用新调度”，立即回到旧逻辑。
- 打开“影子模式”，只观察不干预，确保安全。
- 演示入口与接口都是旁路，只有你打开页面时才会运行。

## 常见问题

1. 指标没变化？先点击“运行编排”。影子模式下不做真实指派，但演示会模拟结果，稍等片刻即可看到变化。
2. 为什么没有走到新调度？需要满足：启用新调度、关闭影子模式、选中了“Agent 白名单”、演示任务类型已包含（默认已配好）。
3. 真正接入要怎么做？把你系统里“任务开始/完成/失败/取消”的事件，旁路调用“镜像事件”方法即可；小范围把新任务改为使用“新调度”，就完成了灰度。具体可咨询我们或查看“协调内核与灰度开关”文档。
