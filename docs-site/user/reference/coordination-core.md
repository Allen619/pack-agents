# 协调内核与灰度开关（通俗版）

一句话说明：这是一个“可随时开/关”的任务编排模块。默认关闭，不改你现在的流程；需要时再逐步启用，随时可退回。

## 它有什么用？

- 把一件大事拆成几步（例如：规划 → 执行 → 总结），并按依赖顺序自动推进。
- 发生失败可重试；超时会中止；可随时取消。
- 先“影子观察”（不干预）确认安全，再小范围启用，最后逐步扩大范围。

## 在哪里？

- 核心代码：`src/packages/coordination-core`
- 演示入口：`/demo/coordination`（左侧菜单可点）

## 如何开启/关闭？

- 在演示页面直接勾选：“启用新调度”“影子模式”“Agent 白名单”。
- 如果需要在服务器层面控制，也可以使用环境变量（可选）：
  - `COORDINATION_ENABLED`：是否启用
  - `COORDINATION_SHADOW_MODE`：是否只观察不干预
  - `COORDINATION_AGENT_ALLOWLIST`：允许启用的新代理名单
  - `COORDINATION_TASKTYPE_ALLOWLIST`：允许启用的新任务类型

建议顺序：先“影子观察”，再小范围启用（白名单），最后逐步扩大。

## 能做什么（简单理解）

- 派发任务：把任务交给某个代理去做。
- 任务依赖：A 做完再做 B，自动控制顺序。
- 超时/重试/取消：超过时间停止；失败可再试；需要时可以取消。
- 查询状态：查看现在有多少任务在排队、运行、完成。

## 想先体验一下？

最简单的方式：打开“协调内核 Demo”页面，按提示勾选开关并选择代理，点击“运行编排”即可。

## 关闭/回退

- 关闭“启用新调度”即可回到旧逻辑。
- 清空“Agent 白名单”也会回到旧逻辑。

## 小提示

- 默认关闭，不会改变任何现有行为。
- 影子模式下只是“看”，不做决定，十分安全。
- 需要细节或二次开发时，再查看源码与接口文档即可。

## 后续计划（建议）

- Phase 1：在现有事件源位置旁路调用 `mirrorEvent()`（不影响主态）
- Phase 2：对白名单入口旁路调用 `assignTask()`，并保留双写对账日志
- Phase X：高级调度策略、资源管理、监控指标、断路器、工作窃取
